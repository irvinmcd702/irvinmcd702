### Oleksandr (Irvin)

Full-stack developer. I keep WordPress sites alive at scale and build the
services around them in TypeScript and Go.

- **WordPress rescue and upgrades** — cleaning hacked sites and finding how
  the attacker got in; moving old sites to PHP 8 without breaking them
  (about 700 so far); monitoring for a fleet of ~1,900 sites.
- **Backends and tools** — Next.js, Node, Go, PostgreSQL; job queues that
  survive failures, admin panels, internal SaaS.
- **LLM integrations** — chat on your own documents, provider fallback, cost
  tracking, MCP servers for agents.
